# QR答案採点システム

学校・塾向けのQR答案採点・成績管理システムです。

## システム構成

- Next.js
- React
- TypeScript
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Cloud Functions
- Google Cloud Vision
- QRコード認識

Firebase Analyticsは使用しません。

## 権限

### 本部管理者

全校舎・全データを管理できます。

### 校舎管理者

所属校舎を管理できます。

### 講師

許可された担当範囲の答案・採点・成績を扱います。

### 生徒

自分の答案・成績のみ閲覧できます。
